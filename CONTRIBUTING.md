# Contributing

Contributions are welcome when they make the instrument clearer, more useful, or easier to understand.

## Before contributing

For substantial changes, open an issue first so the design can be discussed.

## Principles

- Keep the tool local and deterministic unless there is a strong reason to change that boundary.
- Prefer small, explainable features.
- Add tests for behavior that matters.
- Document meaningful design decisions.
- Keep observation separate from interpretation.
